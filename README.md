# Hochwurf

Zwei Nachbarn, ein Sprungtuch und ein Hampelmann, der immer höher fliegt.

- **Wischen:** Tuch verschieben und den Springer auffangen
- **Tippen beim Aufprall:** mehr Schwung (perfektes Timing = Serie)
- **Tippen in der Luft:** Salto (links oder rechts vom Springer tippen)
- Auf den Füßen landen gibt doppelte Punkte, auf dem Kopf kostet es die Serie
- Die Träger haben nur begrenzt Puste, Brezeln in der Luft füllen sie auf

Schuppen mit 8 Aufrüstungen, 6 Springer, 5 Orte (Hinterhof bis Mond), Aufgaben mit Rängen, täglicher Bonus. Offline spielbar als Web-App.
