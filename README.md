# Glutwache

Survival-Action-Spiel fürs Handy. Du bist eine kleine Glutflamme und musst eine Nacht lang gegen immer größere Monsterhorden überleben. Wischen zum Laufen, die Waffen feuern von selbst.

- 8 Waffen mit je 8 Stufen und Meisterwaffen
- 10 passive Gegenstände
- Werkstatt mit 14 dauerhaften Aufrüstungen
- 6 Wächter, 5 Nächte, Härte 1–10, 23 Erfolge
- Offline spielbar (installierbar als App über „Zum Home-Bildschirm“)

## Spielen

Alles steckt in `index.html`. Einmal online öffnen, dann läuft es auch offline.

Lokal: `python3 -m http.server` im Ordner starten und `http://localhost:8000` öffnen.
